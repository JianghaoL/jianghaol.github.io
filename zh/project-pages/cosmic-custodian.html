项目概述

Cosmic Custodian 将经典推箱子玩法重新包装为一款 3D 科幻游戏。玩家需要在网格地图中移动， 避免将箱子推入死角，并把箱子送到目标位置。三个文本关卡、平台自适应教程、可保存的音量设置， 以及可复用的事件层，共同构成了一套完整的游戏流程。

我使用 Unity 6.3.6，在 macOS Sequoia 15.6.1 环境中完成开发。项目采用 URP 与 Unity Input System， 并结合低多边形科幻场景、角色模型、独立 UI 素材、界面音效、背景音乐，以及由 DOTween 驱动的运动反馈。

制作基础

项目由模块化的环境、角色、动画、UI、音乐和音效资源构成。DOTween 负责关卡生成与角色移动的运动语言， 其余部分尽量保持在 Unity 原生工作流之内。

表现层与谜题模型相互分离，使美术、时序和反馈可以独立调整，而不需要重写游戏规则。

文本驱动的关卡编辑

数据驱动的地图管线

关卡不需要逐个摆放物体，而是直接在文本文件中编写。每个字符分别代表墙壁、玩家、箱子、目标点或空白格。 ScriptableObject 则保存预制件、位移、旋转和缩放信息，并把二维记号转换成三维场景。

LevelLoader 从 Application.streamingAssetsPath 读取 LevelData/level_{n}.txt， 逐字解析文本，并把生成的 GridBlock 存入以 Vector2Int 为键的字典。仓库当前包含三个关卡文件， 因此修改谜题时不需要在 Unity 场景中重新手动摆放物体。

确定性的初始化顺序

地图生成依赖当前 Game Config，多个单例系统在启动阶段也存在先后依赖。为使这种顺序清晰可见且稳定可靠， 所有相关类都实现了轻量的 IInitializable 接口。

InitializationManager 会先按 Inspector 中的 order 排序，同步依次调用 InitializeOnAwake， 再经过短暂的实时延迟触发各系统的 InitializeOnStart。接口提供默认空实现， 因此每个类只需要选择自己真正需要的启动阶段。

由设计师控制的启动顺序

带动画的地图生成

MapConstructor 监听 LevelLoader 的完成事件，并根据坐标字典建立棋盘。Game Config 保存每个关卡会变化的参数， 让镜头位置、支撑层数、动画时序和预制件选择都能在不修改构造器的前提下调整。

生成的物体通过 DOTween 协程依次升入场景。随机化的延迟形成有节奏的入场效果， 同时底层谜题状态仍保持确定性。

统一输入契约，多平台控制

PC 端使用 Unity Input System 处理移动、撤销、重新开始和暂停；移动端按钮则通过 IPointerDownHandler 接收触屏输入。 PlatformManager 根据 Application.isMobilePlatform 判断当前模式，UIManager 随后选择桌面端或移动端 UI Handler， TutorialManager 也会显示对应平台的教程文案。两条输入路径最终仍调用同一组 InputHandler 请求方法。

跨平台输入

事件驱动的玩法架构

各玩法系统通过静态 GameEventsManager 协作，避免 Manager 之间互相持有引用。地图加载、镜头与 UI 状态、 移动、网格更新、单步撤销数据、暂停状态、教程节点与胜负检查，都通过职责明确的 UnityEvent 传递。

这种分离让输入、动画、规则和 UI 可以独立测试，也让平台相关代码只承担适配职责， 而不需要复制第二套玩法实现。

不依赖物理系统的网格逻辑

谜题模型由一个 Vector2Int 坐标到格子类型的字典构成，格子类型包括空白、墙壁、玩家、箱子和目标点。 PlayerMovementManager 只允许玩家进入空白、目标点或箱子所在格；遇到箱子时，BoxMovementManager 会单独检查 箱子前方是否为墙壁，在发送任何移动事件前拦截非法推动。

验证通过后，非目标格会立即更新，DOTween 再把可视模型移动到新位置。GameDataManager 会保留目标格原本的类型， 让 WinLoseManager 能在动画结束后识别箱子是否抵达终点。CommandManager 保存最近一次玩家与箱子的前后坐标， 并为最近一步移动提供一次撤销。

移动验证与撤销

轻量的胜利与死角检测

箱子移动后，WinLoseManager 会检查它是否到达目标点。失败检测则使用 HashSet 收集箱子周围的墙壁方向： 超过两面墙表示箱子进入无法推出的 U 形空间；互相垂直的墙壁组合则表示箱子被卡在角落。

该算法无需执行完整路径搜索，就能识别紧凑推箱子地图中最常见的不可逆状态。
